What happens next

  1. Jenkins (riscv-board-pipeline) asks Codex to search the web for the board's official manuals, SoC reference manual, boot guides and vendor sources.
  2. Every link is fetched; links that do not resolve are dropped. Vendor repositories contribute only their board files.
  3. Each runner requirement (boot chain, image format, load address, harts, UART, timer, memory map...) is answered from those documents, with a verbatim quote checked by code.
  4. The memory layout is decided, the runner board files are generated and the firmware is built when enough is known.
  5. This portal shows each requirement with its value and source, and what still needs a person.

Nothing is flashed and no board is touched. The search and analysis take several minutes.
